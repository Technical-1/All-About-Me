## Project Themes

Jacob's projects keep coming back to a few themes:
- **Finishing things** - taking projects past the prototype to something real, documented, and deployed
- **AI as a tool, not an oracle** - language models orchestrate while deterministic code owns the facts
- **Privacy and local-first software** - in-browser analysis, end-to-end encryption, local AI
- **Crypto and personal finance** - explorers, tax-lot accounting, portfolio analytics, budgeting
- **Learning by rebuilding** - the same problem solved in several stacks to learn each one
